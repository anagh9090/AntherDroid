# AntherDroid Repository

Official third-party F-Droid repository for applications developed by **Anagh Barnwal** under the **Anther** series.

This repository allows you to receive direct, fast, and secure updates for Anther apps straight into your F-Droid client without relying on third-party indexers or main store review queues.

## How to Add This Repository to F-Droid

### Option 1: Direct Link (Recommended)
1. Copy this repository URL:
   ```
   https://anagh9090.github.io/AntherDroid/repo
   ```
   
2. Open the **F-Droid app** on your Android device.

3. Go to **Settings ➔ Repositories ➔** Tap the `+` icon.

4. Paste the URL and tap **Add.**

## Security & Verification
All APKs hosted in this repository are compiled, zipaligned, and signed directly by the developer **(Anagh Barnwal)**. The repository index itself is cryptographically signed to ensure update integrity and prevent tampering.
